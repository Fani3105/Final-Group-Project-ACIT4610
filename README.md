# Final-Group-Project-ACIT4610

The ACIT4610 Final Group Project contains two problems, and they share the same Conda enviroment. 

- **Problem 1:** Bees Algorithm (BA) for Travelling Salesman Problem (TSP) and continuous optimization.
- **Problem 2:** Portfolio Optimization using Evolution Strategies (ES).


## Clone the Repository and Install the Environment

cd Final-Group-Project-ACIT4610 <br/>
